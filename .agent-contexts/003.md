# Task #3: Transformer core: parse JS/TS to AST and output canonical form

## What was built

A transformer core module for Bedrock.js that:
- Parses JS/TS source using jscodeshift with correct parser selection (babel or ts)
- Applies a list of `TransformPass` functions over the parsed AST
- Prints the transformed AST back to source
- Returns `{ source, changed }` indicating whether the source was modified

## Key decisions made

- Used `jscodeshift.withParser(parser)` to create a parser-specific jscodeshift instance, ensuring correct parsing of JS vs TS
- The `changed` detection compares output string to input string — simple and reliable
- `TransformPass` is a void-returning function that mutates the AST in place, consistent with jscodeshift's API style
- Kept parse, print, and orchestration in separate files for clarity and future extensibility

## Files changed

- `src/transformer/types.ts` — `TransformPass`, `TransformOptions`, `TransformResult` types
- `src/transformer/parse.ts` — `parseSource()` wrapping jscodeshift with correct parser

## Tests written

- `src/transformer/transform.test.ts` with 7 tests covering:
  - No-op (empty passes): returns `changed: false` and original source (babel + ts)
  - Traversal pass: runs without error and visits correct nodes (babel + ts)
  - Mutating pass: detects change and produces correct output (babel + ts)
  - Multiple passes: applied in order
