# Task #5: Rule: == → ===

## What was built
Implemented the `equality` transformer rule for Bedrock.js that converts loose equality operators (`==`, `!=`) to strict equality operators (`===`, `!==`). Already-strict expressions are left untouched.

## Key decisions made
- Used `BinaryExpression` node filtering on `operator === "=="` and `operator === "!="` as specified
- Followed the exact same pattern as `var-to-const` — a single exported `TransformPass` function
- Named constants for the four operator strings to avoid magic strings
